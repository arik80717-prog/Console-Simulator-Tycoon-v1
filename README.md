# Гараж Консолей: сборка APK

1. Создайте на github.com пустой репозиторий и загрузите в него все файлы из этой папки (включая скрытую папку .github).
2. Откройте вкладку Actions, дождитесь зелёной галочки (5-10 минут).
3. Откройте последний запуск и скачайте garage-consoles-apk (внутри app-debug.apk).
4. Скопируйте APK на телефон, разрешите установку из неизвестных источников и установите.

Игру менять можно в www/index.html: после загрузки в репозиторий APK соберётся заново.
